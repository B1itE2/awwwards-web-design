## 提示词（整段复制）

你是资深前端动效工程师。上一轮你写的 10 个模块整体质量很好，这一轮再写 9 个，接口规则和上一轮完全一样（附件是运行时和示例）。

### 接口规则（和上一轮相同）

1. 文件只包含一次调用：`AW.register('模块名', function (el, o, ctx) { ... return cleanupFn; });`
2. `o` 是 `data-aw-*` 参数（已转 camelCase 和数字/布尔），`ctx = { gsap, ScrollTrigger, lenis, reduced, isMobile }`。
3. 只用全局的 GSAP 3.15、ScrollTrigger、Lenis，不引入其它库，不用 import。
4. `ctx.reduced === true` 时不做动画，直接显示最终状态。
5. 必须返回 cleanup 函数，清掉自己创建的 ScrollTrigger、tween、事件监听、DOM 节点、`requestAnimationFrame`/ticker。
6. 只动画 `transform`、`opacity`、`clip-path`。
7. 缓动只用 `expo.out`（进场）、`power3.out`（交互跟随）、`none`（scrub）。
8. 颜色只用 `var(--ink)`、`var(--bg)`、`var(--accent)`。
9. 顶部注释照 `reveal.js` 格式写：作用、HTML 用法、每个参数和默认值。
10. ES5 风格（`var`、`function`）。

### 上一轮验收发现的问题，这一轮请避免

- **状态不要靠"进入前快照"恢复**。多个同类元素相邻时，快照会记到动画中途的值，回滚就错了。需要全局状态时，每次都根据当前滚动位置重新计算"应该是什么"。
- **跟随鼠标的元素如果用 `mix-blend-mode: difference`，本体用白色 `#fff`**，不要用 `var(--ink)`，否则浅底上看不见。
- **可重复播放的动画，每次开始前要把起点复位**，保证第二次和第一次方向一致。
- **`pointer: coarse`（触摸屏）下，所有鼠标交互模块都不启用**，但内容要正常显示。

### 要写的模块

|---|---|---|---|
| `hover-preview` | 作品列表悬停出图：鼠标移到列表某一行，一张预览图出现在鼠标旁并缓动跟随；换行时图片切换（裁切过渡），移出列表时图片缩小消失 | `lag`(0.25)，`width` 图片宽 px(320)，`ratio` 宽高比("4/5") | 结构：`<ul data-aw="hover-preview"><li data-img="a.jpg">…</li></ul>`；图片预加载；预览层 `pointer-events: none`；切换时旧图向上裁切离开、新图从下裁切进入；触摸屏不启用 |
| `fit-text` | 文字自动缩放到正好撑满容器宽度（页脚巨型字标用） | `max` 最大字号 px(无上限)，`reveal` 是否在进入视口时逐字升起(true) | 只改 `font-size`（这是唯一允许不走 transform 的例外，只在初始化和 resize 时设置一次，不做动画）；字体加载完成后重新计算；容器宽度变化时（用 `ResizeObserver`）重新计算；误差 < 2px |
| `hero-cycle` | 首屏巨字固定不动，背景图片/视频轮换淡入（像 White Desert 的 ANTARCTICA） | `interval` 秒(3.5)，`duration` 交叉淡入时长(1.2) | 结构：`<section data-aw="hero-cycle"><div class="aw-media">多个 img/video</div><h1>…</h1></section>`；同一时间只显示 1 张；视频切到时从头播放、切走时暂停；页面不可见（`visibilitychange`）时暂停轮换；背景图同时做极慢的 1.08→1 缩放 |
| `arc-text` | 文字沿圆弧排列（SVG textPath），滚动时整圈缓慢旋转 | `radius` 半径 px(160)，`arc` 弧度角度，360 为整圈(360)，`spin` 滚过该区域旋转的度数(90)，`size` 字号 px(14) | 读取元素原文字生成 SVG；文字等距铺满弧线；`spin` 为 0 时不旋转；scrub 绑定滚动，回滚倒转；原文字保留给屏幕阅读器（`aria-label`） |
| `rotate` | 通用滚动旋转（唱片、齿轮、罗盘等实物隐喻） | `turns` 滚过区域时转几圈(1)，`start`("top bottom")，`end`("bottom top") | scrub；`turns` 可为负数（反向）；作用于元素自身 |
| `drag-gallery` | 横向拖拽画廊：鼠标/手指拖动一行图片，松手带惯性滑行，到边缘有阻尼回弹 | `friction` 惯性衰减(0.92)，`edge` 边缘阻尼(0.35) | 结构：`<div data-aw="drag-gallery"><div class="aw-track">…</div></div>`；拖动时光标为 `grab/grabbing`；拖动超过 5px 时阻止子元素的点击（避免误点链接）；同时支持横向滚轮/触控板；触摸屏也启用（这是例外） |
| `menu` | 全屏菜单：点击按钮后，遮罩从上方裁切展开，菜单链接逐行遮罩升起；再次点击或按 Esc 关闭（反向播放） | `stagger`(0.06) | 结构：`<button data-aw="menu" data-aw-target="#menu">Menu</button>` + `<nav id="menu"><a>…</a></nav>`；打开时 `ctx.lenis.stop()`，关闭时 `start()`；按钮文字在 Menu / Close 之间切换；设置 `aria-expanded`；打开后焦点移到第一个链接，关闭后回到按钮；点击菜单内的锚点链接后自动关闭 |
| `dot-matrix` | 点阵字标：用 canvas 把一个单词画成点阵（像 Opal 的 opal 字标），鼠标经过时附近的点被推开再弹回 | `text`(必填)，`gap` 点间距 px(8)，`dot` 点半径 px(1.6)，`radius` 鼠标影响半径 px(90)，`font` 字体(取元素的 font-family，粗细 800) | canvas 用 `devicePixelRatio` 保证清晰；点阵通过离屏 canvas 绘字后取像素生成；颜色取元素计算后的 `color`；只在元素进入视口时运行动画循环（用 `IntersectionObserver`），离开时停止；resize 重建；触摸屏和 reduced 时画静态点阵 |
| `hover-swap` | 文字悬停换字体：鼠标移到链接/按钮上，文字从无衬线滚动切换成衬线斜体（上下双层，旧层上移、新层从下升起） | `font` 替换字体("var(--font-serif)")，`italic`(true) | 自动把元素文字复制成两层，外层 `overflow: hidden`，宽度取两层较宽者避免抖动；两层都 `aria-hidden`，外层保留 `aria-label`；触摸屏不启用 |
