# Kimi 任务包 01：动效模块

**使用方法**：新开一个 Kimi 对话，把下面「提示词」整段贴进去，并上传这 3 个文件作为参考：
- `awwwards-web/assets/starter/js/aw-core.js`（模块接口）
- `awwwards-web/assets/modules/reveal.js`（标准写法示例）
- `awwwards-web/assets/modules/clock.js`（滚动 scrub 示例）

Kimi 每写完一个模块，把代码存成 `awwwards-web/assets/modules/<名字>.js`。全部写完后交回给 Kiro 验收。

---

## 提示词（整段复制）

你是资深前端动效工程师。我在做一个生成 Awwwards 级网页的工具库，已经写好了运行时 `aw-core.js` 和两个示例模块 `reveal.js`、`clock.js`（附件）。请严格按同样的写法，写下面 10 个模块，每个模块一个独立 JS 文件。

### 必须遵守的接口

1. 文件只包含一次调用：`AW.register('模块名', function (el, o, ctx) { ... return cleanupFn; });`
2. `el` 是挂载元素，`o` 是 `data-aw-*` 参数（已自动转 camelCase 和数字/布尔），`ctx = { gsap, ScrollTrigger, lenis, reduced, isMobile }`。
3. 只用全局的 GSAP 3.15、ScrollTrigger、Lenis，不引入任何其它库，不用 ES module / import。
4. `ctx.reduced === true`（用户开启减少动效）时：不做动画，直接显示最终状态，然后 return。
5. 必须返回 cleanup 函数，kill 掉自己创建的 ScrollTrigger / tween / 事件监听。
6. 只动画 `transform`、`opacity`、`clip-path`，不动 width/height/top/left。
7. 缓动只用：`expo.out`（进场）、`power3.out`（交互跟随）、`none`（scrub）。
8. 颜色只用 CSS 变量 `var(--ink)`、`var(--bg)`、`var(--accent)`，不写死颜色。
9. 模块需要的 CSS 用 JS 内联设置，或者在文件顶部注释里写明需要加的 CSS（不超过 15 行）。
10. 文件顶部注释照 `reveal.js` 的格式：模块作用 + HTML 用法 + 每个参数及默认值。
11. ES5 语法风格（`var`、`function`），和示例保持一致。

### 要写的模块

| 名字 | 效果 | 参数（默认值） | 验收标准 |
|---|---|---|---|
| `marquee` | 跑马灯：子元素无缝循环横向滚动；滚动页面时速度加快，方向跟随滚动方向 | `speed` 每秒像素(80)，`direction` 1 或 -1(1)，`boost` 滚动加速倍数(3) | 无缝无跳帧；窗口缩放后重新计算宽度；内容不足一屏宽时自动复制填满 |
| `counter` | 数字计数：进入视口时从 0 滚到目标数 | `to`(必填)，`from`(0)，`duration`(1.6)，`decimals`(0)，`separator` 千位分隔符(",")，`suffix`("") | 只播一次；最终值精确等于 `to`；数字用 `font-variant-numeric: tabular-nums` 防抖动 |
| `odometer` | 里程表：每位数字是竖向滚轮，滚动页面时数字从 from 滚到 to（scrub，回滚倒转） | `from`(0)，`to`(必填)，`start`("top 80%")，`end`("bottom 20%") | 每位独立滚动，进位时高位一起转；每位用 overflow 遮罩，只露 1 个数字高度 |
| `cursor` | 自定义光标：一个小圆点跟随鼠标（带缓动延迟），悬停在 `a, button, [data-cursor]` 上时放大；`data-cursor="文字"` 时圆内显示该文字 | `size`(12)，`hover-size`(64)，`lag` 跟随系数(0.18) | 挂在 `<body data-aw="cursor">`；触摸设备（`pointer: coarse`）不启用；原生光标隐藏但输入框内恢复；用 `mix-blend-mode: difference` |
| `magnetic` | 磁吸：鼠标靠近按钮时按钮朝鼠标偏移，离开弹回 | `strength`(0.35)，`radius` 触发半径 px(80) | 弹回用 `elastic.out(1, 0.4)`；触摸设备不启用 |
| `parallax` | 视差：元素随滚动以不同速度移动 | `speed`(0.2，正数慢于页面，负数反向)，`scale` 图片放大避免露边(1.15) | 如果元素内有 `img`，移动 img 而不是容器，容器 overflow hidden；scrub |
| `img-reveal` | 图片揭示：进入视口时 clip-path 从一边打开，同时图片从 1.3 缩放到 1 | `from` "bottom"/"top"/"left"/"right"("bottom")，`duration`(1.4) | 只播一次；用 `inset()` 裁切，不用 polygon |
| `scribble` | 手绘圈：悬停时一个手绘风格的椭圆 SVG 线条把元素圈起来（像 A24 站），离开时线条反向擦除 | `color`("var(--accent)")，`stroke`(1.5) | 椭圆路径要不规则、首尾错开一点（像手画），用 `stroke-dasharray` 描线，描线时长 0.6s |
| `hscroll` | 横向滚动：区块钉住，内部一行卡片随纵向滚动横向移动 | `speed` 滚动距离倍数(1) | 结构 `<section data-aw="hscroll"><div class="aw-track">卡片…</div></section>`；移动距离 = track 宽度 − 视口宽度；手机端（`ctx.isMobile`）改为原生横向滑动 |
| `theme` | 章节换色：`<section data-aw="theme" data-aw-bg="#111" data-aw-ink="#f2f1ee">` 滚到视口中线时，整页 `--bg`、`--ink`（可选 `--accent`）平滑过渡到该章节的颜色，离开时还原上一个 | `bg`、`ink`、`accent`（可选） | 改的是 `document.documentElement` 上的 CSS 变量；过渡 0.6s；多个 theme 区块连续时颜色正确衔接，往回滚也正确 |

### 交付格式

每个模块只给出完整的文件代码，用代码块包起来，代码块上一行写文件名。不要写解释、不要写测试页面。
