# 交付前检查

逐条过。任何一条不通过就修，修完再交付。

## 版式

- [ ] 首屏有且只有一个主角（巨字 / 大图 / 物件），占视口 60% 以上。
- [ ] 首屏不是"居中标题 + 副标题 + 两个按钮"。
- [ ] 字号只有两极：展示字 ≥ 5vw，其余 ≤ 18px。没有大量 24–32px 的中号标题。
- [ ] 展示字字距是负数，行高 ≤ 1.0。
- [ ] 正文每段 ≤ 60 个汉字 / 40 个英文词，最宽 36ch。
- [ ] 元素都对齐到 12 栏栅格线；页边距统一用 `--margin`。
- [ ] 四角 UI 在位，内容不和四角重叠（首屏顶部留够空间）。
- [ ] 章节之间留白充足（≥ 20vh），页面看起来"空"是对的。
- [ ] 图片只用 1–2 种比例。

## 颜色与字体

- [ ] 每屏只有 bg + ink + 最多 1 个 accent。accent 只出现在 CTA、当前态或一个关键数字上。
- [ ] 没有渐变按钮、阴影卡片、emoji 图标。
- [ ] 最多 2 个字体家族 + 1 个等宽。
- [ ] 中文标题用了合适的回退字体，字距比西文松。

## 文案

- [ ] 没有 lorem ipsum、没有"赋能 / 一站式 / 极致体验 / 打造"。
- [ ] 展示字每行 1–4 个词。
- [ ] 占位内容（图片、联系方式）在交付说明里列出来了。

## 动效

- [ ] 每屏最多一个进场效果（全局的光标、平滑滚动不算）。
- [ ] 叙事性动效跟着滚动（scrub），回滚时倒放。
- [ ] 实物模块（clock / odometer / rotate）最多 1 个，而且和主题有关。
- [ ] 首屏标题用 `data-aw-on="load"`，预载结束后才播放。
- [ ] 没有飞入、弹跳、360° 旋转进场。

## 工程

- [ ] 用浏览器打开没有控制台报错。
- [ ] 禁用 JS 时内容仍然可读（不会全部 `opacity: 0`）。
- [ ] 系统开启"减少动态效果"时，页面正常可读，没有动画。
- [ ] 手机宽度（375px）下：没有横向滚动条，巨字不溢出，四角只保留上面两个。
- [ ] 所有资源是相对路径、本地文件，断网能打开。
- [ ] `<title>` 和 `<meta name="description">` 已填写。
- [ ] 图片有 `alt`；装饰性图片 `alt=""`。

